# kotemado

開いたウィンドウを、決めておいた**ディスプレイ**の決めておいた**位置・大きさ**へ自動で置く常駐ソフトです。
Maximize Assistant と同じ役目を、今の Windows 向けに作り直しました。

- **インストール不要。** `kotemado.exe` を好きな場所に置いて起動するだけ。
- **レジストリを使わない。** 設定は exe と同じ場所の `kotemado.ini`（UTF-8 のテキスト）だけ。
  「Windows の起動時に開始」もスタートアップ フォルダのショートカットで行います。
- **軽い。** exe 1 個（約 190KB）。ウィンドウを定期的に見回らず、Windows からの
  「ウィンドウが表示された」という通知にだけ反応するので、待っている間の CPU 使用はゼロです。

## Maximize Assistant との違い

| | Maximize Assistant | kotemado |
|---|---|---|
| 対象の指定 | キャプションとクラス名の AND だけ | **プロセス名**・クラス名・キャプションを、それぞれ「指定しない／完全一致／前方一致／後方一致／部分一致／ワイルドカード」で。指定した項目の AND |
| キャプションのないウィンドウ | 指定しにくい | 「完全一致」で空欄にすれば指定できる。プロセス名だけでも指定できる |
| 位置の基準 | ディスプレイ 1 の左上からの座標 | **ディスプレイ番号**＋そのディスプレイの中の座標（画面全体か、タスクバーを除いた作業領域か） |
| 指定の仕方 | ピクセル・% | ピクセル・%・**中央** |
| Windows 10/11 の透明な縁 | 縁の分だけずれる | 見た目の枠で合わせる（切り替え可） |
| 拡大率の違うディスプレイ | — | 移した先の拡大率で大きさを合わせ直す |
| 画面 | 昔の UI | Windows 11 の標準的な見た目。ライト／ダークはシステムに合わせる |

## 使い方

1. `kotemado.exe` を起動すると、最初だけ設定画面が開きます。以後は通知領域（タスクトレイ）に常駐します。
2. 動かしたいウィンドウを、置きたい場所・大きさにしておきます。
3. 設定画面の「追加」で、照準（左上の赤い丸）をクリックし、続けてそのウィンドウをクリックします。
   プロセス名・クラス名・キャプションが「完全一致」で、今の位置・大きさとともに入ります。
   キャプションが開いている文書で変わるアプリなら、「前方一致」などに変えるか、
   「指定しない」にして使わないようにしてください。
   選んでいる間はマウスの下のウィンドウが赤い枠で囲まれます。選ぶためのクリックは相手のアプリには届きません。
   右クリックか Esc で中止します。
4. 必要なら一致方法を変えて「OK」。次からそのウィンドウが開くたびに、その場所へ置かれます。

「該当を確認」で、今開いているウィンドウのうち条件に合うものを一覧できます。
「今すぐ試す」で、保存する前にその設定で実際に動かせます。

トレイのアイコンをクリックすると設定画面、右クリックで「今すぐ適用」「一時停止」「ディスプレイ番号を表示」「終了」。

### ディスプレイ番号

番号は Windows が付けているディスプレイの番号（`\\.\DISPLAY1` の `1`）です。
「ディスプレイ番号を表示」で、各画面の中央に大きく番号が出ます。
指定したディスプレイがつながっていないときは、そのウィンドウは動かしません。

ディスプレイには、ほかに「メイン ディスプレイ」と「ウィンドウが今あるディスプレイ（移さない）」も選べます。

### 位置と大きさ

| 書き方 | 意味 |
|---|---|
| 空欄 | 変えない |
| `100` | 基準の左上から 100 ピクセル（物理ピクセル） |
| `50%` | 基準の幅（高さ）の 50% |
| `中央` | 基準の中央に置く（X・Y のみ） |

基準は「画面全体」か「作業領域（タスクバーを除く）」を選べます。

### タイミング

- **ウィンドウごとに最初の 1 回だけ**（既定）: 開いたときに置いたら、あとは自由に動かせます。
- **定期的に**: 指定した間隔（既定 1000 ミリ秒）ごとに位置を確かめ、ずれていたら戻します。
  手で動かしても、アプリが自分で動いても、最小化から戻しても、元の場所へ戻ります。
  位置が合っている間は何もしないので、間隔を短くしても負荷はほとんどありません
  （100 ミリ秒間隔で 10 秒見回って CPU 時間 0ms）。つかんで動かしている最中は待ちます。
  kotemado の開始時や、ルールを追加・変更したときに開いている窓も対象になります。
- キャプションを条件にしていると、キャプションが変わって**別のルールに合うようになったとき**にも置き直します
  （ブラウザで開いたページごとに置き場所を変える、といった使い方ができます）。
- 表示の直後に自分で位置を戻すアプリには、**遅延**（200〜500 ミリ秒ほど）を入れると確実です。

## 設定ファイル

`kotemado.ini` は手で書き換えてもかまいません（kotemado を止めてから）。

```ini
[general]
apply_existing=1            ; kotemado の開始時に、開いているウィンドウにも適用する

[rule]
name=メモ帳
enabled=1
exe=exact:notepad.exe       ; 一致方法:文字列。any exact prefix suffix contains wildcard
class=any:
title=any:
display=2                   ; 番号 / main / current
base=work                   ; screen(画面全体) / work(作業領域)
x=center
y=0
width=50%
height=100%
frame=visible               ; visible(見た目の枠) / window(窓の矩形)
state=keep                  ; keep / normal / max / min
topmost=keep                ; keep / on / off
when=once                   ; once(最初の 1 回だけ) / periodic(定期的に)
interval=1000               ; 定期的にのときの間隔(ミリ秒、100〜100000)
delay=0                     ; ミリ秒
```

ルールは上から順に調べ、最初に条件が合ったものを使います。
プロセス名に `\` を含めると、ファイル名ではなくフルパスと比べます。

隠し設定として `[general]` に `theme=light` / `theme=dark` を書くと、配色をシステムと関係なく固定できます。
`log=1` で動作の記録を `kotemado.log` に書きます。

exe を書き込めない場所（Program Files など）に置いた場合は、`%APPDATA%\kotemado\kotemado.ini` を使います。

## コマンドライン

```
kotemado.exe                常駐を始める（すでに動いていれば設定画面を出す）
kotemado.exe -settings      常駐を始めて設定画面を出す
kotemado.exe -apply         動いている kotemado に「今すぐ適用」させる
kotemado.exe -exit          動いている kotemado を終わらせる
kotemado.exe -ini <path>    設定ファイルを指定する
kotemado.exe -log           動作の記録を書く
```

## 注意

- **管理者として実行しているウィンドウ**は、kotemado も管理者として実行しないと動かせません（Windows の制限）。
- ストア アプリ（電卓など）は、プロセス名が `ApplicationFrameHost.exe` になることがあります。
  クラス名（`ApplicationFrameWindow`）とキャプションで指定してください。
- 最大化を指定したウィンドウは、最大化と同時に前面に出ます（Windows の仕様）。

## やめるとき

トレイの「終了」で止め、`kotemado.exe` と `kotemado.ini` を消せば跡は残りません。
「Windows の起動時に開始」を使っていた場合は、先にチェックを外すか、
スタートアップ フォルダ（`shell:startup`）の `kotemado.lnk` を消してください。
